# 🍔 Multi-Restaurant Food Delivery App


🔗 **[Live Demo](https\://m0hammedsahal.github.io/restorant/)**

A powerful **Django-based food delivery platform** connecting customers with multiple restaurants. Styled with **Tailwind CSS** for a smooth and modern experience. 🛵💨

## 🚀 Features  
✅ **Customers:** Browse restaurants, add to cart, apply coupons, place & track orders. 📱  
✅ **Restaurants:** Manage menus, orders & offers via dashboard. 🧑‍🍳  
✅ **Admin:** Control users, restaurants, orders & site analytics. 📊  

## 🏗️ Tech Stack  
🖥 **Backend:** Django, Django REST Framework  
🎨 **Frontend:** Tailwind CSS, JavaScript  
🗄 **Database:** PostgreSQL / MySQL  
🔐 **Auth:** Django Auth + AJAX  

## ⚡ Quick Start  
```bash
git clone https://github.com/yourusername/food-delivery-app.git
cd food-delivery-app
pip install -r requirements.txt
python manage.py migrate
python manage.py runserver
```
